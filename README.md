# Cyberthrone – Downloads

Hier liegen nur die Windows-Installer von Cyberthrone. Der Quellcode ist privat.

**Installieren:** [Cyberthrone-Setup.exe herunterladen](https://github.com/tscherny86/cyberthrone-releases/releases/latest/download/Cyberthrone-Setup.exe) (immer die neueste Version, ab 2.2.0), doppelklicken, „Installieren“. Danach startet Cyberthrone über die Verknüpfung im Startmenü oder auf dem Desktop und aktualisiert sich selbst.

Windows fragt beim ersten Start einmal nach, weil das Setup nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.

Ältere Versionen: [alle Releases](https://github.com/tscherny86/cyberthrone-releases/releases).
